# 흑과 백

더 지니어스 데스매치 '흑과 백'을 브라우저에서 즐기는 1:1 심리전 웹 게임입니다.

▶ **플레이:** https://jkh76.github.io/bnw/

설치 없이 스마트폰·태블릿·PC 브라우저에서 바로 실행됩니다. 빌드 도구 없이 `index.html` 한 파일로 동작합니다.

## 게임 방법

### 공통 규칙
- 선 플레이어가 먼저 비공개로 내면 **색만 공개**되고, 후 플레이어가 그 색을 보고 냅니다. 큰 쪽이 그 라운드를 이깁니다.
- 상대가 낸 숫자는 게임이 끝날 때까지 공개되지 않습니다. 색과 승패만 보입니다.
- 이긴 사람이 다음 라운드 선이 되고, 비기면 선이 그대로 유지됩니다.
- **5승**을 먼저 하면 즉시 승리합니다. 9라운드가 끝나 승수가 같으면 무승부(재경기)입니다.
- 첫 라운드 선은 동전 던지기로 정합니다.

### 흑과 백 (버전 A)
- 각자 0~8 타일 9장을 가집니다.
- 짝수(0 포함)는 **흑**, 홀수는 **백**입니다.
- 낸 타일은 다시 쓸 수 없습니다.

### 흑과 백 2 (버전 B)
- 각자 99포인트로 시작해 매 라운드 원하는 만큼 겁니다(0 포인트도 가능).
- 건 포인트는 이기든 지든 사라집니다.
- 0~9는 **흑**, 10~99는 **백**으로 공개됩니다. 같은 포인트면 무승부입니다.
- 남은 포인트는 5칸 표시등으로 공개됩니다. 80·60·40·20 미만으로 내려갈 때마다 한 칸씩 꺼집니다(마지막 칸은 꺼지지 않음).

## 모드
- **AI 대전:** 쉬움 / 보통 / 어려움
- **친구와 한 기기:** 차례마다 화면을 가리고 넘겨서 2인 플레이
- **추리 메모:** 지금까지 공개된 정보로 상대가 낸 수를 추리해 보여줍니다(메뉴에서 켜고 끄기).

## 기타

- 설정은 브라우저에 저장됩니다.
